# Y!News Filter Plus

Yahoo!ニュースをキーワードとJevの関連性判定でハイライト・除外するChrome拡張。Yahoo! JAPAN非公式です。独立した拡張への移植初版は **0.1.0** です。

RakuFillと同じManifest V3・TypeScript・Vite・CRXJS構成を採用しています。判定・設定UIの本体は動作を維持するためJavaScriptで移植し、保存・同期・通信の基盤をTypeScriptで実装しています。

## 開発

Node.js 22.12以降の対応版を使用します（作成時検証：Node.js 26）。

```sh
npm ci
npm run icons
npm test
npm run build
npm run package
```

`chrome://extensions` でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」で `dist/` を選びます。Yahoo!ニュースを開き直し、拡張アイコンまたはページ上の件数チップから設定を開きます。Yahoo以外では拡張アイコンから設定専用タブを開きます。

## ユーザースクリプトからの移行

1. 現在のY!News Excluder Plusの設定画面で「設定を書き出す」を押し、JSONを保存します。
2. 本拡張を読み込み、設定の「バックアップ・移行」→「設定を読み込む」でそのJSONを選びます。
3. 置き換え確認後、通常キーワード、興味のある／ない条件、しきい値、本文追加判定、並列数などが反映されます。自動保存です。
4. Jev APIキーは移行JSONに含まれません。各端末で入力してください。GitHubトークン・Gist IDは不要です。
5. 設定を確認して、Tampermonkey側のユーザースクリプトを無効にします。Yahooを再読み込みしてください。両方を同時に有効にすると二重の非表示・Jev通信が起こり得ます。

移行前のJSONは手元に残してください。現在の拡張設定を置き換える場合、以前の設定は保存履歴（直近10件）から復元できます。

## Chrome同期

初期状態では有効です。同じGoogleアカウントでChromeの拡張機能同期を有効にする必要があります。GistやGoogle Drive APIは使いません。

- 同期：通常キーワード、Jevの条件・有効状態・数値パラメータ・表示設定。
- 端末内のみ：Jev APIキー、判定キャッシュ、保存履歴。
- ページ内のみ：一時解除、通信統計と詳細ログ。
- 手動で開いた判定HTMLはブラウザのセッション保存領域に保存します。

Chrome同期領域と一致していても、他端末への到着完了までは保証できません。拡張機能IDが異なる開発用インストール間では同期できません。複数端末テストでは同じストアアイテムのテスト版を使用するか、同一IDとなる開発設定が必要です。

同時編集はベクター時計で検出し、設定を勝手に上書きしません。「複数端末間のChrome同期」内で候補を比較して解決します。データは端末ごとのスナップショットを分割保存し、ハッシュが一致しない到着途中のデータは取り込みません。Chromeの約100KBの制限に対し95KBの余裕を持った上限を設けています。複数端末のスナップショット全体が上限に含まれます。上限・通信失敗時もローカル設定と再送予定を保持します。

## 構成

- `src/content/engine.js`：記事抽出、通常除外、Jev判定・キャッシュ、設定UI。
- `src/shared/settings.js`：設定の検証・正規化・移行形式。
- `src/shared/bridge.ts`：ページ／設定UIから拡張基盤へのアダプター。
- `src/shared/sync.ts`：分割・検証・競合検出。
- `src/background/`：保存の直列化、Chrome同期、Jev／本文通信、表のタブ作成。
- `src/dashboard/`：Yahooを開いていなくても使用できる設定ページ。
- `src/report/`：判定詳細のHTML表・絞り込み。

## 検証範囲

自動テストは設定移行、正規化、記事のキーワード除外、同期初回取り込み、並行編集、競合解決、容量超過、破損データ、秘密情報の同期除外を検証します。型検査・ビルドも実施しています。

実Chromeへの読み込み、実アカウントでの複数端末同期、実Jev APIへの課金を伴う問い合わせ、Chrome Web Store審査は未実施です。公開前に `docs/TESTING.md` を確認してください。
