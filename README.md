# Y!News Filter Plus

Yahoo!ニュースの記事一覧を、キーワード、または Jev（TypeSafe AI 社の API）による関連性判定でハイライト・除外する Chrome 拡張です。Yahoo! JAPAN とは無関係な非公式のソフトウェアです。

## 機能

- **キーワード除外**：指定した語を含む記事カードを非表示にします。全角・半角、アクセント、中黒の有無などの表記ゆれを吸収して照合します。
- **Jev による判定（任意）**：「興味のあるキーワード」に関連する記事をハイライトし、「興味のないキーワード」に関連する記事を除外します。見出しだけでは判断が曖昧な記事は、本文冒頭も取得して追加判定できます。
- **Chrome 同期**：キーワードと判定条件を、同じ Google アカウントの Chrome 間で同期します。同時編集の競合は自動で上書きせず、比較して選べます。
- **判定詳細**：Jev の判定値・採用した根拠・エラーを表で確認し、TSV でコピーできます。
- **設定の書き出し・読み込み**：JSON でバックアップ・移行できます。直近 10 件の保存履歴から復元もできます。

## Jev について（重要）

Jev は任意の機能で、**初期状態では無効**です。利用するには [TypeSafe AI](https://typesafe.ai/) で API キーを取得し、設定画面に登録してください。**API の利用料金は利用者と TypeSafe AI 社との契約に基づいて発生します。** 本拡張の開発者は料金を受け取らず、API キーや判定内容を取得することもありません。Jev を有効にすると、記事の見出し（本文追加判定を有効にした場合は本文冒頭も）と判定条件が `api.typesafe.ai` に送信されます。詳細は[プライバシーポリシー](docs/PRIVACY_POLICY.md)をご覧ください。

API キーは端末内の拡張機能ストレージに保存され、Chrome 同期や設定 JSON には含まれません。各端末で入力してください。

## 導入

Chrome Web Store で公開後、ここにリンクを掲載します。

開発版を使う場合は、下記の手順でビルドし、`chrome://extensions` でデベロッパーモードを有効にして「パッケージ化されていない拡張機能を読み込む」から `dist/` を選びます。

## 使い方

1. Yahoo!ニュース（`news.yahoo.co.jp`）を開くと、ページ右上に「○件非表示中」のチップが表示されます。チップまたはツールバーの拡張アイコンをクリックすると設定画面が開きます。Yahoo!ニュース以外のページでは、拡張アイコンから設定専用タブが開きます。
2. 「除外キーワード」に非表示にしたい語を 1 行に 1 つ入力します。設定は自動保存されます。
3. 行末に `||` を付けると、その行だけの条件を指定できます。
   - `ABC||case:1`：大文字・小文字を区別する（`case:0` で区別しない）。
   - `単語||rate:90`：一致した 10 件のうち 9 件を除外する。`rate:90!` は先頭の 1 件を表示して残りを除外します。
4. Jev を使う場合は「意味によるハイライト/除外判定」を開き、API キーを登録して「Jev を有効にする」をオンにし、興味のある／ないキーワードを入力します。
5. チップにマウスを載せると、現在非表示にしている語の一覧が出ます。語をクリックすると一時的に除外を解除できます。

動作対象のドメインは `news.yahoo.co.jp`、`www.yahoo.co.jp`、`sports.yahoo.co.jp`、`baseball.yahoo.co.jp`、`soccer.yahoo.co.jp`、`keiba.yahoo.co.jp` です。

## ユーザースクリプト版からの移行

1. ユーザースクリプト版の設定画面で「設定を書き出す」を押し、JSON を保存します。
2. 本拡張の設定画面で「バックアップ・移行」→「設定を読み込む」からその JSON を選びます。通常キーワード、興味のある／ない条件、しきい値、本文追加判定、同時問い合わせ数などが反映されます。
3. Jev API キーは JSON に含まれないため、各端末で入力し直してください。
4. ユーザースクリプト版を無効にし、Yahoo!ニュースを再読み込みしてください。両方を同時に有効にすると、二重の非表示や Jev への二重送信が起こり得ます。

読み込み前の設定は「保存履歴から復元」で戻せます。

## Chrome 同期

初期状態では有効です。同じ Google アカウントで Chrome の拡張機能同期を有効にする必要があります。設定画面の「複数端末間の Chrome 同期」から停止できます。

- 同期するもの：通常キーワード、Jev の条件・有効状態・数値パラメータ・表示設定。
- 端末内のみ：Jev API キー、判定キャッシュ、保存履歴。
- ページ内のみ：一時解除、通信統計と詳細ログ。
- 手動で開いた判定詳細の表は、ブラウザのセッション保存領域に置き、ブラウザを閉じると消えます。

## ビルド

Node.js 22.12 以降を使用します（作成時検証：Node.js 26）。

```sh
npm ci
npm run icons
npm test
npm run build
npm run package
```

`npm run package` で `release/ynews-filter-plus-<version>.zip` と sha256 が生成されます。

## 構成

- `src/content/engine.js`：記事抽出、通常除外、Jev 判定・キャッシュ、設定 UI。
- `src/content/selectors.js`：記事カードのセレクター定義（原作由来）。
- `src/shared/settings.js`：設定の検証・正規化・移行形式。
- `src/shared/bridge.ts`：ページ／設定 UI から拡張基盤へのアダプター。
- `src/shared/sync.ts`：分割・検証・競合検出。
- `src/shared/hosts.ts`：動作対象ドメインの一覧。
- `src/background/`：保存の直列化、Chrome 同期、Jev／本文通信、表のタブ作成。
- `src/dashboard/`：Yahoo を開いていなくても使用できる設定ページ。
- `src/report/`：判定詳細の HTML 表・絞り込み。
