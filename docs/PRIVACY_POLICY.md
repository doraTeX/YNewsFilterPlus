# Y!News Filter Plus プライバシーポリシー

最終更新日：2026年10月22日

Y!News Filter Plus（以下「本拡張機能」）は、Google Chrome 用の拡張機能であり、Yahoo!ニュースの記事を利用者が指定した条件に応じてハイライト・非表示にします。本拡張機能は Yahoo! JAPAN とは無関係な非公式のソフトウェアです。本ポリシーは、本拡張機能が扱うデータの内容と取り扱いについて説明します。

## 収集しない情報

本拡張機能は、開発者のサーバーを持たず、利用者のデータを開発者や広告・アクセス解析事業者へ送信しません。閲覧履歴、操作記録、氏名・メールアドレス等の個人を識別する情報も収集しません。

## 扱うデータと保存場所

本拡張機能が扱うデータは以下のみです。いずれも Chrome の拡張機能ストレージ API を通じて保存します。

| データ | 保存場所 |
| --- | --- |
| 除外キーワード、AI の判定条件（興味のある／ないキーワード）、しきい値などの数値設定、表示設定 | `chrome.storage.local`（端末内）および、Chrome 同期が有効な場合は `chrome.storage.sync` |
| AI接続先・モデル・サーバーURL・アカウントID・APIキー | `chrome.storage.local`（端末内のみ。Chrome 同期や設定 JSON の書き出しには含めません） |
| AI の判定結果キャッシュ（記事の URL・見出し・判定値）、設定の復元履歴（直近 10 件） | `chrome.storage.local`（端末内のみ） |
| 手動で開いた「判定詳細」の表 | `chrome.storage.session`（ブラウザを閉じると消えます） |

## Chrome 同期について

Chrome 同期は初期状態で有効です。利用者が Chrome にログインし、拡張機能の同期を有効にしている場合、上記の「設定」に分類したデータは Google が提供する Chrome 同期の仕組みを通じて、同じ Google アカウントの他の端末に同期されます。これは Chrome 標準の機能であり、開発者が独自にサーバーを運用してデータを収集・保管するものではありません。同期は設定画面の「複数端末間の Chrome 同期」からいつでも停止できます。

## AI判定への送信について

AIによる関連性判定は任意の機能で、**初期状態では無効**です。設定して有効にすると、選択した接続先へ次のデータを送信します。

- 記事カードの見出し（リンクテキスト）と、利用者が入力した判定条件。記事URLは送信しません。
- 「本文も取得して追加判定する」を有効にした場合、判断が曖昧だった記事のページをYahoo!ニュースから取得し、見出しと本文冒頭（最大2,000文字）を判定先へ送信します。
- APIキーを変更した場合、認証確認のため「接続確認」という短いテキストと質問を送信します。
- Ollayaの「モデル一覧を取得」では、指定したサーバーにモデル一覧を問い合わせます。この操作では記事や判定条件を送りません。

APIキーは各接続先への認証にのみ使用し、端末内の拡張機能ストレージに平文で保存します。暗号化された保管庫であることは保証しません。OllayaにはAPIキーを送りません。共有端末では接続先を選んで「APIキーを削除」を押してください。別の接続先で保存したキーは、その接続先を選んで個別に削除できます。クラウドAPIの利用料金および送信先でのデータの取り扱いは、利用者と各サービスとの契約・規約に従います。

## 通信先

- Yahoo! JAPANの各ドメイン（`news.yahoo.co.jp`、`www.yahoo.co.jp`、`sports.yahoo.co.jp`、`baseball.yahoo.co.jp`、`soccer.yahoo.co.jp`、`keiba.yahoo.co.jp`）：記事一覧の抽出と、本文追加判定時の記事ページ取得。
- Jev：`api.typesafe.ai`。
- Cloudflare Clef：`api.cloudflare.com` の設定したアカウントのWorkers AI。
- OpenAI Decisions：`api.openai.com`。
- Ollaya：利用者が指定したサーバー。初期値は `http://localhost:11435`。別PCや外部ホストを指定した場合は、そのサーバーへ送信されます。

AI判定は選択中の1つの接続先にのみ送信します。別サービスへの自動切替は行いません。

## 利用者が書き出すデータ

設定画面の「設定を書き出す」で保存する JSON には、キーワード・判定条件・各種設定が含まれます（API キーは含みません）。「判定詳細を TSV でコピー」や「判定詳細を表で開く」で得られるデータには、記事の見出し・URL・判定条件・判定値が含まれます。これらは利用者の端末内で完結する操作であり、開発者へ送信されることはありません。

## データの削除

設定画面から、キーワードや判定条件の編集、API キーの削除、判定キャッシュの消去ができます。Chrome の拡張機能管理画面から本拡張機能をアンインストールすると、`chrome.storage.local` に保存されたデータは端末から削除されます。`chrome.storage.sync` 上のデータは Chrome の同期設定に従います。書き出した JSON や TSV は利用者自身で削除してください。

## 権限について

| 権限 | 用途 |
| --- | --- |
| `storage` | 上記のデータを `chrome.storage` に読み書きするため |
| `alarms` | Chrome 同期の再試行と定期確認のため |
| `clipboardWrite` | 判定詳細を TSV 形式でクリップボードへコピーするため |
| ホスト権限（Yahoo! JAPAN の上記ドメイン） | 記事一覧の抽出・非表示・ハイライト、および本文追加判定時の記事ページ取得のため |
| ホスト権限（`api.typesafe.ai`） | Jevの判定要求のため |
| 任意のHTTP／HTTPSホスト権限 | Clef・OpenAI・Ollayaの接続先について、ユーザー操作時に個別に許可を求めるため。宣言だけで全ホストへのアクセスを許可するものではありません |
