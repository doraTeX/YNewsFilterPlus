# 実Chromeでの受入確認

自動テストとビルドは完了。以下は実環境で未実施です。

- distを読み込み、コンソールに起動エラーがない。
- Yahooトップ・記事ページ・ランキングで記事だけが処理され、コメントや「次へ」が対象にならない。
- キーワードの入力直後と再読み込み後で設定が保持される。
- ユーザースクリプトのJSONを取り込み、全条件と数値が一致。旧スクリプトを無効にして二重処理を防ぐ。
- 設定タブ・Yahoo上の設定画面の同時編集で、古い画面からの上書きを拒否する。
- 同じ拡張ID・同じGoogleアカウントの2端末で、新規端末に空の設定で上書きされず取り込まれる。
- オフラインで両端末を編集→再接続時に競合を表示。選択解決後に両端末が一致。
- Jevキーは他端末に同期されない。
- Jevを明示的に有効化して見出し判定・本文追加判定・課金統計・一時解除を確認。
- APIエラー・時間切れ・上限時も記事表示と設定が壊れない。
- 詳細表を開き、絞り込み・行色・元ページのリンク・TSVコピーを確認。
- サービスワーカー停止後も、設定保存・再起動・アラームで同期処理が再開。
